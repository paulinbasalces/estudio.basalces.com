##  Sobre o Projeto

Landing page de alta conversão para o serviço de criação de sites profissionais do Estúdio Basalces. O site tem como objetivo principal **vender o pacote anual de R$ 1.621** para profissionais liberais e pequenos negócios, transmitindo credibilidade, profissionalismo e diferenciação frente a soluções amadoras (Wix, WordPress genérico, "sobrinho").

### Público-alvo
- Profissionais liberais (advogados, psicólogos, médicos, consultores)
- Pequenos negócios (restaurantes, clínicas, salões, prestadores de serviços)
- Pessoas que valorizam design autoral e suporte humano

### Não é para
- Lojas virtuais / e-commerce
- Quem busca soluções gratuitas ou muito baratas
- Sistemas complexos com funcionalidades avançadas

## 💡 Ideais e Princípios

O projeto segue os valores profissionais de Paulin Basalces, refletidos em cada decisão de design e código:

### 1. **Inclusão como método, não como discurso**
Acessibilidade real, não performática. Se uma feature de acessibilidade quebrar o site, ela deve ser removida — melhor não existir do que existir pela metade.

### 2. **Design estratégico com foco em resultado**
Cada elemento visual existe para vender. Nada é decorativo sem propósito. O site é uma ferramenta de conversão, não um portfólio de vaidade.

### 3. **Transparência radical**
Preço claro, condições explícitas, sem pegadinhas. O cliente sabe exatamente o que está comprando antes de clicar em "Quero meu site".

### 4. **Código limpo e manutenível**
HTML semântico, CSS organizado, JavaScript mínimo e funcional. Sem dependências pesadas, sem frameworks desnecessários.

### 5. **Performance acima de tudo**
Site leve, rápido, que carrega em menos de 2 segundos. Cada kilobyte importa.

### 6. **Mobile-first de verdade**
Mais de 70% do tráfego vem de dispositivos móveis. O site deve funcionar perfeitamente em qualquer tela.
